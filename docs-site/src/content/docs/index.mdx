## What it does

<CardGrid stagger>
  <Card title="Inbound Management" icon="document">
    **ASN → Receiving → QC → Putaway** with directed bin assignment and
    zero-value stock tracking on behalf of each client.
  </Card>
  <Card title="Outbound Fulfillment" icon="rocket">
    **Client Order → Wave → Pick → Pack → Ship** with FIFO/FEFO allocation
    and automatic Delivery Note creation.
  </Card>
  <Card title="Automated Billing" icon="seti:db">
    Every warehouse activity auto-logs a **Billing Transaction** with rate
    lookup from per-client **Rate Cards**.
  </Card>
  <Card title="Configurable Rules" icon="setting">
    **Inventory Policies** drive picking, putaway and QC rules per client,
    zone, and item group — no code edits needed.
  </Card>
  <Card title="Built on ERPNext" icon="seti:stylus">
    Extends the ERPNext Stock module — single source of truth, full audit
    trail, standard accounting.
  </Card>
  <Card title="Multi-Client Isolation" icon="puzzle">
    Shared warehouse, isolated data. Each client sees only their inventory
    via Frappe role permissions.
  </Card>
</CardGrid>
